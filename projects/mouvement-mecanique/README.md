# Sources de démonstration (contenu inventé)

Les trois fichiers de `sources/` ont été **inventés par Claude** pour tester le générateur (ADR 0013). Ils ne
viennent d'aucun client ni d'aucune marque, et ne citent aucun calibre réel. Ce sont des faits
horlogers généraux, publiquement documentés.

- `guide-mouvement.pdf` : guide du conseiller (rédigé en DOCX, converti en PDF par LibreOffice)
- `argumentaire.pptx` : argumentaire de vente en 10 diapositives, avec un schéma
- `notes-terrain.docx` : questions fréquentes de clients

Pour les régénérer : `python3 scripts/demo-sources/make_mouvement_sources.py projects/mouvement-mecanique/sources`
