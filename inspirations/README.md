# Inspirations

Ce que Sam dépose ici sert à **s'inspirer**, jamais à copier : on en tire des principes
(rythme, hiérarchie, interactions, ton), notés dans `notes.md`, puis on les applique avec nos
propres dessins et nos propres textes.

Du plus utile au moins utile :
1. **Lien vers le module en ligne** (lien de partage Rise ou Review 360, Genially, site…), dans
   `liens.md` : Claude l'ouvre dans un vrai navigateur, le parcourt, mesure et capture.
2. **Export SCORM ou HTML5 (ZIP)** : rangé dans `modules/`, **ignoré par git** (droits d'auteur,
   poids). Claude le lance comme un LMS et lit aussi sa construction.
3. **Vidéo d'écran** (MP4, MOV) : idéale pour les animations et transitions quand on n'a pas
   le module ; Claude en extrait les images clés.
4. **Captures** : bien pour la mise en page, muettes sur le mouvement.
5. PDF : en dernier recours.

Pour chaque élément, une ligne de note : ce qui plaît, et ce qui ne plaît pas.

⚠️ Module d'un client ou d'un employeur = confidentiel : il ne quitte pas le dossier
`modules/` et n'est envoyé à aucun autre service.
